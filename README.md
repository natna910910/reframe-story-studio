# Reframe Story Studio

你是一名资深AI产品设计师、UX设计师和前端工程师。请帮我开发一个可实际点击和交互的高保真网页产品Demo，产品名称为 ReFrame AI。

【一、项目背景】

产品定位：ReFrame AI 是一款面向需要将同一组视频素材适配不同受众的短视频创作者的AI叙事重构工具。它根据目标受众重新规划镜头选择、叙事顺序、字幕和信息重点，并支持用户锁定重要镜头后，仅重新生成未锁定部分。

核心价值：同一组素材，面向不同受众，讲出不同的故事；AI负责建议，创作者保留控制权。

请使用 React、TypeScript、Tailwind CSS 和 shadcn/ui 等适合的技术。无需真实AI API、后端、账号、数据库或视频渲染服务。使用本地Mock数据模拟AI分析和生成，但交互、状态和结果必须真实联动。

【二、整体UI/UX视觉设计规范 】

请将 ReFrame AI 设计成一款成熟、专业、克制的内容创作SaaS工具，而不是典型的AI生成工具。视觉关键词：Warm Minimalism、Editorial Workspace、Calm Productivity、Content-first。

1. 整体视觉方向

- 采用浅色模式，暖白色为主背景，雾蓝色为主要强调色。

- 风格简洁、精致、理性、有呼吸感，避免强烈的AI科技感。

- 参考 Linear、Notion 等产品的信息组织方式，以及专业视频编辑器的工作台布局，但不直接复制。

- 优先突出用户素材、故事板、预览画面和编辑操作，而不是突出AI品牌元素。

2. Design Tokens

- 页面背景：#FAF9F6（Warm White）

- 主面板背景：#FFFFFF

- 次级面板背景：#F3F3F0

- 分割线/边框：#E7E8E5

- 主文字：#242424

- 次级文字：#737780

- 主强调色：#626B83（Muted Slate Blue）

- 强调色Hover：#515B73

- 选中状态背景：#E8EDF3

- 强调色浅底：#F0F3F7

- 成功状态：#547E6B

- 警告状态：#B48750

- 错误状态：#B86661

- 锁定状态：#626B83

请统一使用这些颜色变量，不要在不同组件中随机使用其他紫色、蓝色或渐变。

3. 排版

- 使用 Inter + Noto Sans SC 或系统无衬线字体。

- 页面标题20–24px，区块标题15–17px，正文13–14px，辅助信息12px。

- 文字层级清晰，避免过粗的标题和大面积加粗。

- 标题字重600，正文400–500。

- 行高舒适，重要内容有适当留白。

- 所有中文文案使用自然、专业、简洁的产品语言。

4. 页面布局

- 顶部工具栏高度约56px，展示品牌、项目名称、当前步骤及主要操作。

- 左侧窄导航栏约64px，使用简洁线性图标。

- 左侧素材面板约240–270px。

- 中央为主要编辑区域，包含受众版本切换、镜头故事板、操作工具。

- 中右区域为9:16竖屏预览，宽度约230–270px。

- 最右侧为AI解释和创作建议面板，宽度约260–300px。

- 在常见桌面屏幕下合理压缩布局，避免横向溢出；较窄屏幕可折叠侧边面板。

- 使用细边框和轻微阴影区分面板，不要使用大量悬浮卡片。

- 故事板是视觉核心，素材缩略图和镜头信息要清楚可读。

5. 组件规范

- 圆角：普通按钮6–8px，卡片8–10px，主要面板10–12px。

- 按钮：主按钮使用雾蓝底色+白色文字；次级按钮使用白底+浅灰边框。

- 选中状态：浅雾蓝背景+细雾蓝边框，避免高饱和发光效果。

- 锁定镜头：使用小型实心锁图标和克制的雾蓝状态标识。

- 镜头卡片：展示缩略图、镜头ID、名称、时长、字幕、选镜原因、锁定操作。

- AI解释：使用简洁的信息卡片或侧栏文本，不使用大面积彩色背景。

- 图标统一使用Lucide线性图标。

- 表单、标签、弹窗和Toast保持统一的间距、圆角与色彩。

6. 交互与动效

- 页面切换和面板展开采用150–200ms的轻量过渡。

- 加载状态使用简洁进度提示或骨架屏，不使用炫目的AI粒子动画。

- 局部重新生成后，通过浅雾蓝背景高亮变更镜头，并标注“已调整”“已保留”。

- 锁定操作即时反馈，允许撤销。

- Hover、Focus、Disabled状态必须明确。

- 支持键盘焦点可见，保持文字与背景的良好对比度。

- 不要为了视觉效果牺牲可读性或操作效率。

7. 明确禁止的视觉元素

- 不使用霓虹紫、荧光蓝、赛博朋克色彩。

- 不使用紫蓝渐变按钮、渐变背景或发光边框。

- 不使用玻璃拟态、强烈背景模糊、大面积阴影。

- 不使用大量星星、魔法棒、机器人头像或AI装饰图标。

- 不使用夸张的营销首页、巨大Slogan或无意义数据看板。

- 不使用Emoji作为主要功能图标。

- 不使用过度圆润的胶囊按钮和过大的卡片间距。

8. 设计目标

让评审第一眼觉得这是一个真正可以投入使用的视频内容创作工作台，而不是AI工具自动生成的模板网站。

整个界面的视觉主角应该是用户素材、故事板和镜头编辑操作。

AI能力通过功能与交互体现，而不是通过炫目的视觉符号体现。

请将以上视觉规范应用到首页、素材分析、创作方向、故事板编辑、版本对比、预览与导出以及所有异常状态。其他业务逻辑和功能需求保持不变。

【三、固定演示项目】

项目名称：周末咖啡馆探店

素材：8段镜头，所有镜头有固定且唯一的ID、标题、时长、描述、视觉缩略图、内容标签。

S01：咖啡店门头，4秒，店铺外观

S02：咖啡馆环境，5秒，阳光与座位

S03：菜单价格，4秒，饮品价格与优惠

S04：咖啡制作，6秒，咖啡师制作饮品

S05：咖啡拉花，5秒，拿铁特写

S06：甜点展示，4秒，甜品与咖啡组合

S07：靠窗阅读，5秒，安静的阅读场景

S08：朋友聊天，5秒，轻松愉快的社交场景

请为每个镜头提供符合描述的可展示缩略图。优先使用可靠的静态图片资源；如果外部图片无法加载，必须有漂亮的本地占位设计，不允许出现破损图片图标。

首页提供两个入口：

1. 体验示例项目（主要演示路径，点击即可进入）

2. 上传自己的素材（支持选择本地视频或图片并预览，但提示自定义素材的真实AI分析暂未接入；不能假装已经分析了上传内容）

【四、核心用户流程】

页面/状态1：项目入口

展示产品名称、简短产品说明和示例项目卡片。

主要按钮：体验示例项目。

点击后进入素材工作台。

页面/状态2：素材分析

展示8个素材卡片，包含缩略图、镜头编号、名称、时长和AI识别标签。

展示“AI已识别8段素材”的演示状态。

用户可查看单个素材详情。

按钮：下一步，设置创作方向。

页面/状态3：创作方向

用户可以选择目标受众：

A. 留学生 / 预算敏感人群

B. 都市白领 / 生活方式爱好者

可选择创作目标：

A. 实用攻略

B. 情绪氛围

预设两种组合：

组合A：留学生 + 实用攻略

组合B：都市白领 + 情绪氛围

展示清晰的受众和目标描述。

按钮：AI生成叙事方案。

页面/状态4：AI生成

点击生成后进入1—2秒的模拟加载状态。

加载时展示阶段文案：理解素材内容、匹配受众关注点、规划叙事结构。

生成结束后展示对应的故事板。

提供可主动触发的“模拟生成失败”入口，用于展示失败状态。

失败时保留用户已选参数，展示明确错误说明及重试按钮。

不可用的操作必须有合理反馈，不能点击无反应。

页面/状态5：故事板及双版本对比

这是整个Demo最重要的页面。

组合A输出：

标题：《留学生探店：这家咖啡馆到底值不值？》

镜头顺序：S01 → S03 → S06 → S04 → S05

叙事重点：位置与价格、产品内容、性价比

字幕示例：

S01：周末发现一家值得收藏的咖啡馆

S03：先看看菜单和价格

S06：咖啡搭配甜点，值不值得点？

S04：现场制作，看看出品过程

S05：最后看看这杯拿铁的表现

组合B输出：

标题：《把周末交给阳光和一杯咖啡》

镜头顺序：S02 → S07 → S04 → S05 → S08

叙事重点：空间氛围、情绪体验、周末放松

字幕示例：

S02：终于找到一个可以慢下来的地方

S07：在阳光下读几页喜欢的书

S04：听咖啡机慢慢工作的声音

S05：一杯拿铁，让时间变得柔软

S08：和朋友聊天，就是最好的周末

必须展示两个版本的镜头级差异，而不只是标题差异。

允许用户切换版本、查看镜头顺序、字幕和选镜原因。

每个镜头卡片都展示“AI为什么选择这个镜头”的简短解释。

示例：S03菜单价格镜头被选择，因为预算敏感用户更关心消费信息。

示例：S07靠窗阅读镜头被选择，因为生活方式受众更关注放松氛围。

页面/状态6：故事板编辑与局部重生成

每个镜头卡片提供锁定/解锁按钮，状态必须明显。

支持用户通过上移/下移按钮调整未锁定镜头顺序。

锁定后，该镜头的ID、字幕、位置在局部重新生成时保持不变。

点击“局部重新生成”后：

- 显示模拟加载

- 仅修改未锁定镜头的选择、顺序或字幕

- 已锁定镜头保持完全不变

- 用可视化标签标出新增、调整和保留的镜头

- 展示重新生成前后的差异摘要

- 支持撤销本次重新生成，恢复上一个版本

- 如果所有镜头均锁定，禁用重新生成并解释原因

- 如果锁定镜头过多导致无法调整，给出清晰提示

重要：必须实现基于镜头ID的状态管理，不允许只改变页面上的提示文字来假装重新生成。

局部重生成使用预设的替代故事板和确定性规则，不调用真实模型。生成结果必须符合当前受众目标，且不能引用不存在的素材。

用户手动编辑后再重新生成，锁定约束仍然有效。

页面/状态7：预览和导出

展示9:16竖屏故事板预览，包含镜头缩略图、字幕、时长和播放进度。

可以用定时切换静态镜头的方式模拟视频预览，明确标注为故事板预览，不宣称已渲染真实视频。

支持播放、暂停、重播。

提供导出创作方案按钮，真实下载JSON或TXT文件，包含标题、受众、创作目标、镜头顺序、字幕、选镜理由及锁定状态。

明确提示：当前Demo不支持真实视频渲染和MP4导出。

【五、交互与状态要求】

必须覆盖：

1. 初始状态

2. 已选择素材状态

3. 生成中状态

4. 生成成功状态

5. 生成失败与重试状态

6. 锁定与解锁状态

7. 局部重新生成前后状态

8. 撤销状态

9. 全部锁定时的限制状态

10. 预览与导出完成状态

所有核心按钮必须能工作。

不能出现死链、空白页面、无意义弹窗或伪成功提示。

状态切换不能丢失用户已确认的锁定信息。

支持返回上一步。

确保刷新后不会产生异常；不要求持久化数据。

【六、Demo说明】

在界面适当位置标注：

“产品概念演示 · AI生成结果由预设数据模拟”

不要声称已经接入真实AI模型。

用户可随时重置示例项目，重新体验完整流程。

【七、验收标准】

1. 用户能从首页顺利进入示例项目。

2. 能查看8段素材及标签。

3. 能选择两种不同受众并生成明显不同的故事板。

4. 每个镜头有可查看的选镜理由。

5. 能锁定一个镜头，局部重新生成后锁定镜头的ID、位置、字幕不变。

6. 未锁定镜头发生可见的合理变化。

7. 能撤销局部重新生成。

8. 能体验加载、失败和重试。

9. 能播放模拟故事板预览。

10. 能真实导出故事板方案文件。

11. 所有关键流程无运行错误。

12. 视觉设计完整，适合AI产品经理校招笔试展示。

请直接实现完整可运行的网页Demo，不要只输出产品说明、设计建议或静态页面。优先保证核心流程与交互可靠性，再优化视觉细节。
